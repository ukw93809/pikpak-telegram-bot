**PikPak 是什么：先建立基本认知**

很多人第一次听说 PikPak，会以为它只是另一个网盘。其实不太一样。

普通网盘的核心价值是"存文件"——你先本地下好，再上传进去。PikPak 的逻辑反过来：**你把下载任务扔给它，它的服务器代替你下载，下完放你云盘里**，你只需要拿取。

支持的资源格式包括：BT 种子（.torrent 文件）、磁力链接（Magnet Link）、HTTP/HTTPS 直链，以及 X（Twitter）、TikTok、Facebook 等社交媒体上的视频分享链接。

超过 80% 的文件能在几秒内完成云端保存。存进去之后，4K 原画质在线播放也是支持的，不需要下到本地再播，服务器那边做好转码，你直接串流看就行。

客户端覆盖了主流平台：Android、iOS、Windows、macOS（Apple 芯片机型）、Android TV，以及网页版，还支持 WebDAV（会员专属），可以接 Infuse、nPlayer 这类第三方播放器。

**PikPak Telegram机器人：它是什么，能做什么**

PikPak 官方的 Telegram Bot 账号叫 **@PikPak\_Bot**，是 PikPak 官方发布和维护的机器人。

**@PikPak\_Bot 支持接收的内容：**

如果你有多个 PikPak 账号，或者想把 Bot 切换到另一个账号，操作流程如下：

3. 打开 PikPak App → 「我的」→「连接 Telegram Bot」→ 选择「新增连接」

**常见问题快速回答**

**Q：Bot 收到链接后一直没有反应，怎么办？**

先确认账号绑定是否成功（给 Bot 发 `/start` 检查状态）。如果绑定正常但没有响应，可能是该资源被 PikPak 的内容审核屏蔽了（PikPak 会屏蔽部分违规内容），或者是链接本身已经失效。

**Q：Bot 转存的文件在云盘哪里找？**

默认保存在 PikPak 云盘根目录或"我的文件"下，以下载任务为单位分文件夹存放，打开 App 或网页版就能看到。

**Q：免费用户可以使用 Telegram Bot 吗？**

可以，免费用户同样可以绑定并使用 @PikPak\_Bot，但受制于免费版的速度限制和 6GB 存储上限，实际体验会打不少折扣。

**Q：PikPak 有没有官方兑换码或者优惠活动？**

PikPak 不定期会有首次订阅优惠活动（需要注意的是，首次订阅优惠只在第一次订阅时生效，取消后重新订阅不能再享受）。此外，PikPak 提供礼品卡服务，可以在第三方分销渠道购买兑换码，官方授权的分销方式是通过兑换码进行。
